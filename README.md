## Постановка задачі

Необхідно розробити програму, яка приймає числові показники (з файлу CSV), перетворює їх на параметри MIDI та автоматично створює MIDI-файл. Кожен показник повинен впливати щонайменше на один параметр MIDI. Програма повинна забезпечувати математичну нормалізацію даних, пояснювати правила перетворення, будувати візуальний графік та забезпечувати інтерактивне відтворення отриманого результату.

У цій реалізації використовуються такі вхідні та згенеровані параметри MIDI:

| Параметр | Допустимі значення | Призначення |
| :--- | :--- | :--- |
| **Pitch** | `0..127` (робочий: `36..84`) | Визначає висоту MIDI-ноти (автоматично розраховується з вхідних даних) |
| **Velocity** | `1..127` (робочий: `40..110`) | Визначає силу та динаміку звучання (акустичну гучність) |
| **Duration** | `120..960` ticks | Тривалість ноти у MIDI-тіках ($0.25..2.0$ чверті при 480 TPQN) |
| **Instrument** | `1..128` | Інструмент стандарту General MIDI |

## Особливості проєкту

* **Універсальна математична нормалізація:** Автоматичне масштабування будь-яких реальних даних (курсів акцій, температури, тиску, рівня радіації тощо) у коректні діапазони MIDI ($0..127$).
* **Багатоканальна поліфонія:** Можливість передачі кількох стовпців даних для створення багатоголосних композицій (дуетів чи ансамблів) з різними інструментами на окремих MIDI-каналах.
* **Інтерактивний плеєр із прогрес-баром:** Вбудоване відтворення згенерованого MIDI-файлу прямо в терміналі через `pygame` з анімованим консольним статус-баром `[██████----] %`.
* **Автоматична візуалізація:** Побудова та збереження наочних графіків у форматі PNG за допомогою `matplotlib` для порівняння часових рядів зі звуком.
* **Гнучке налаштування через CLI:** Повний контроль над вибором стовпців, темпом, інструментами та назвами вихідних файлів через аргументи командного рядка.
* **Модульна архітектура (Clean Architecture):** Чітке розділення бізнес-логіки (`core/`), візуалізації (`ui/`) та інтерфейсу користувача (`main.py`).

## Правила перетворення даних

### 1. Нормалізація

Будь-які вхідні дані $x \in [x_{\min}, x_{\max}]$ приводяться до цільового MIDI-діапазону $[Y_{\min}, Y_{\max}]$ за формулою:

$$
Y = \left\lfloor \frac{x - x_{\min}}{x_{\max} - x_{\min}} \cdot (Y_{\max} - Y_{\min}) + Y_{\min} \right\rfloor
$$

### 2. Висота ноти (Pitch)

Вхідні значення нормалізуються у діапазон `36..84` (від C2 до C6). Додатково номер ноти перетворюється на музичну назву:

$$
\text{Octave} = \lfloor \text{Pitch} / 12 \rfloor - 1, \quad \text{Note} = \text{Notes}[\text{Pitch} \bmod 12]
$$

*Приклади:* $60 \rightarrow \text{C4}$, $64 \rightarrow \text{E4}$, $67 \rightarrow \text{G4}$, $72 \rightarrow \text{C5}$.

### 3. Сила удару (Velocity)

Нормалізується у діапазон `40..110`. Інтерпретація гучності:

* `1..40` $\rightarrow$ тихо
* `41..80` $\rightarrow$ середньо
* `81..110` $\rightarrow$ голосно
* `111..127` $\rightarrow$ дуже голосно

### 4. Тривалість (Duration)

Вхідні значення нормалізуються у діапазон `120..960` ticks (при роздільній здатності 480 TPQN):

* $120 \text{ ticks} = 0.25$ долі (шістнадцята нота)
* $240 \text{ ticks} = 0.5$ долі (восьма нота)
* $480 \text{ ticks} = 1.0$ доля (чвертна нота)
* $960 \text{ ticks} = 2.0$ долі (половинна нота)

### 5. MIDI-інструмент

Користувач задає номер $1..128$, який перетворюється у номер програми MIDI $0..127$:

$$
\text{ProgramNumber} = \text{Instrument} - 1
$$

## Algoritм роботи програми

1. Програма зчитує вказаний CSV-файл через `pandas`.
2. Перевіряється наявність вказаних стовпців та їхня числова валідність.
3. Модуль `visualizer` створює графік часових рядів та зберігає його у PNG.
4. Модуль `midi_builder` виконує нормалізацію вхідних масивів для кожного треку.
5. Для кожного стовпця формуються MIDI-події `program_change`, `note_on` та `note_off`.
6. Створюється файл Standard MIDI File (`.mid`) із налаштованим темпом.
7. У консоль виводиться журнал нормалізації та приклад мапінгу перших нот.
8. Програма запитує підтвердження на відтворення (якщо не вказано `--play`) та запускає аудіоплеєр із анімованим прогрес-баром.

## Встановлення та запуск

### 1. Налаштування середовища (Linux / macOS / Windows)

```bash
# Створення віртуального середовища
python3 -m venv venv

# Активація середовища (Linux/macOS)
source venv/bin/activate

# Активація середовища (Windows PowerShell)
# .\venv\Scripts\Activate.ps1

# Встановлення залежностей
pip install -r requirements.txt
```

### 2. Приклади запуску

**1) Стандартний запуск (із запитом на відтворення):**
```bash
python main.py my_test.csv --pitch Stock_Price --velocity Trading_Volume
```

**2) Запуск із прямою вказівкою автовідтворення:**
```bash
python main.py my_test.csv --pitch Stock_Price --velocity Trading_Volume --play
```

**3) Багатоканальний запуск (Поліфонія) з власними іменами файлів:**
```bash
python main.py my_test.csv \
  --pitch Stock_Price Trading_Volume \
  --velocity Trading_Volume \
  --instrument 1 41 \
  --bpm 140 \
  --out-midi finance_composition.mid \
  --out-plot finance_chart.png \
  --play
```

**4) Перегляд інструкції з усіх прапорців:**
```bash
python main.py -h
```

## Контрольний приклад

**Вхідний файл `my_test.csv`:**

```csv
Stock_Price,Trading_Volume
150,5000
165,10000
130,20000
```

**Результати обробки:**

1. `Stock_Price` ($130..165$) $\rightarrow$ `Pitch` ($36..84$):
   * $150 \rightarrow 63$ (D#4)
   * $165 \rightarrow 84$ (C6)
   * $130 \rightarrow 36$ (C2)
2. `Trading_Volume` ($5000..20000$) $\rightarrow$ `Velocity` ($40..110$):
   * $5000 \rightarrow 40$ (тихо)
   * $10000 \rightarrow 63$ (середньо)
   * $20000 \rightarrow 110$ (голосно)

## Перевірка коректності та валідація

| Перевірка | Некоректні дані | Реакція програми |
